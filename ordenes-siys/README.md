# Biblioteca local de órdenes SI&S

Cada carpeta conserva el snapshot, evidencia visual, borradores, aprobaciones, entregables y auditoría de una orden. Los archivos operativos están excluidos de Git por contener información de servicio.

La carpeta se identifica con `codigo--sede--fecha`; `metadata.json` conserva el ID único de SI&S para distinguir órdenes históricas con el mismo código.
