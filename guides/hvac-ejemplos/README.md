# Ejemplos de redacción HVAC

Esta carpeta es la fuente humana de estilo para mejorar informes SIYS. Agrega o ajusta archivos Markdown por tipo de equipo; el analizador visual los carga como guía, pero nunca los usa para afirmar labores que no estén respaldadas por la orden, sus fotografías o las notas del técnico.

## Cómo agregar un ejemplo

1. Crea un archivo con un nombre corto, por ejemplo `minisplit.md` o `chiller-aire-agua.md`.
2. Describe el equipo, el tipo de servicio y varias redacciones modelo.
3. Separa siempre lo ejecutado, el hallazgo y la recomendación.
4. Incluye solo actividades que el técnico pueda confirmar mediante nota o fotografía.

## Regla de evidencia

La guía establece el vocabulario y la estructura. La evidencia de cada orden establece qué se puede decir. Si una foto no permite confirmar un componente, una medida o una acción, el analizador debe marcarlo para revisión y no agregarlo al texto.

## Convención recomendada

```md
## Mantenimiento preventivo

### Evidencia mínima
- Filtros, serpentín, blower, bandeja o drenaje visibles.

### Redacción modelo
Se realizó ...

### No afirmar sin evidencia
- Temperaturas, presiones, amperajes o refrigerante.
```

Los archivos iniciales sirven de punto de partida y se pueden ampliar con ejemplos aprobados de clientes y marcas.
